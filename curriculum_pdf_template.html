Detailed Requirements
Capstone Project Deliverables

To graduate from the program and receive their Certificate, every team must design, build, and deploy a complete AI-powered application containing:

1. Codebase & Documentation

  • Clean Repository: Modular Python architecture versioned on GitHub with isolated configs.
  • API Contract: Standard FastAPI routes documented via interactive Swagger UI.
  • System Architecture: Detailed README containing a visual database and data flow diagram.

2. AI Core & Database Integrations

  • Semantic Indexing: Structured document ingestion using Qdrant collections.
  • Grounded Context (RAG): Prompt logic connected to the Kinyarwanda-first EjoChat API.
  • Output Enforcement: Strict JSON output schemas parsed and validated via Pydantic.

3. DevOps & Hosting

  • Containerization: Production-ready Dockerfile and local multi-service Compose scripts.
  • Serverless Cloud: Live public API hosted on Google Cloud Run.
  • Automation Pipeline: CI/CD setup via GitHub Actions triggering builds on merge.

4. Production Best Practices

  • Security Guards: Safe credentials storage and mitigation filters for prompt injections.
  • Observability Tracing: Instrumented telemetry traces sent to Langfuse.
  • Clean Log Pipes: Centralized error capturing and structured runtime logging.
