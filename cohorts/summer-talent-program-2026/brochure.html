Executive Summary

Why This Program Exists

The Ejo Labs Summer Talent Program 2026 introduces young learners to software engineering, Artificial Intelligence, and cloud computing through beginner-friendly, hands-on practice. The program gives participants a structured way to spend the holiday building useful technical skills, working in teams, and growing confidence through real projects.

University participants build toward a portfolio-ready AI application, while high school participants discover programming, computational thinking, and responsible AI through guided projects. Both tracks share selected joint sessions so students can learn from each other while still following a pace that fits their starting level.

Teaching Philosophy

We believe in AI for Everyone, empowering youth to lead the next wave of technology enthusiasts across Africa. By demystifying artificial intelligence and equipping young minds with practical engineering skills, we cultivate community innovators who not only master modern technology, but actively teach, inspire, and uplift their local communities to build a digitally empowered future.

Fast Facts

Level: Beginner-friendly. No prior AI experience is required.

Structure: Orientation, weekly hands-on sessions, joint learning moments, and a shared Closing / Hackathon Day.

Capstone: One continuous project developed step by step, ending with demos, awards, certificates, and networking.

Week 1 — Software Engineering Foundations Building baseline application code
Session 1 10:00 - 12:00 CAT
Tuesday, 28 July 2026

Introduction to AI Engineering & Environment Setup

Lead Lecturer: Bosco Kalinijabo

Learning Objectives:

  • Differentiate AI Engineering roles from traditional development and ML research.
  • Configure clean virtual Python runtimes and environment configurations.
  • Execute atomic Git operations and collaborative team branch workflows.

Topics Covered:

  • Core AI concepts: What AI can and cannot do, how ChatGPT works conceptually, and Responsible AI.
  • Intro to AI coding assistants (Cursor, Claude Code, Gemini CLI, Copilot) and environment setup (VS Code, Python runtime, virtual environments).
  • Professional Git workflow: commit standards, branch naming, pull requests, and code reviews.

Practical Lab: Initialize the team GitHub repository, configure environment settings, and push the initial project structure.

Session Deliverables: A shared GitHub repository containing active virtual environment configurations and a merged Pull Request verifying Python runtime execution.

Session 2 10:00 - 12:00 CAT
Friday, 31 July 2026

Backend Development Fundamentals

Lecturers: Bosco Kalinijabo & Neha Fathima

Learning Objectives:

  • Explain REST API operations and standard HTTP request-response patterns.
  • Build functional backend endpoints in Python using FastAPI.
  • Design database tables and perform basic queries using PostgreSQL and SQLModel ORM.

Topics Covered:

  • FastAPI routing: headers, payloads, query parameters, type checking, and auto-documentation.
  • Relational database design, SQL schemas, environment variables (.env files), and credentials safety.
  • Backend testing strategies and API verification using Postman.

Practical Lab: Build core API routes for item creation and retrieval, and link the application to a local PostgreSQL instance.

Session Deliverables: A running FastAPI backend server connected to a database, verified with active Postman testing requests.

Week 2 — AI Product Thinking & Prompt Engineering Designing UX and crafting model prompts
Session 3 10:00 - 12:00 CAT
Tuesday, 4 August 2026

AI Product Design (Joint with HS Track)

Lecturers: Bosco Kalinijabo & Prof. Dr. Manuel Oriol

Learning Objectives:

  • Determine when to solve problems with generative AI versus traditional software algorithms.
  • Design UI/UX experiences that communicate model latency and handle output uncertainty.
  • Calculate running token costs (COGS) and understand AI business models.

Topics Covered:

  • Spotting high-value AI use cases, defining value propositions, and levels of automation.
  • AI UX patterns: streaming responses, edit controls, failure fallbacks, and retry mechanisms.
  • Ethical AI design: privacy, security, user consent, governance, and regulations.

Practical Lab: Map user personas, sketch UX/UI layouts, and build operating cost matrices for the capstone idea.

Session Deliverables: A Product Specification sheet outlining target personas, UI wireframes, and fallback handlers.

Session 4 (Joint) 10:00 - 12:00 CAT
Friday, 7 August 2026

Prompt Engineering & LLM Fundamentals (Joint with HS Track)

Lead Lecturer: Bosco Kalinijabo

Learning Objectives:

  • Write clear, structured prompts using instructions, context, role prompting, and few-shot examples.
  • Understand token mechanics, context windows, temperature ranges, and how hallucinations occur.
  • Debug prompts and keep track of prompt versions during project work.

Topics Covered:

  • Core prompt architecture: instructions, background context, few-shot examples, and format constraints.
  • Prompting AI coding assistants effectively to optimize development speed.
  • Model selection basics: balancing cost, speed, and quality for different tasks.

Practical Lab: Write and test prompts for a few different AI tasks, then compare what makes a prompt clear or confusing.

Session Deliverables: A small set of tested prompt examples for the capstone project.

Week 3 — AI Integration & Solution Design Implementing RAG pipelines and operational audits
Session 5 10:00 - 12:00 CAT
Tuesday, 11 August 2026

AI Integration & Retrieval-Augmented Generation (RAG)

Lecturers: Ejo Labs Team & Henry Okonkwo

Learning Objectives:

  • Integrate Large Language Models into backend code with structured JSON output enforcement.
  • Implement document parsing, semantic text chunking, and overlap limits.
  • Connect and query the Qdrant vector database for grounded context retrieval.

Topics Covered:

  • Calling model APIs from Python, handling response streaming, and structured Pydantic parsing.
  • Vector search fundamentals: embeddings generation, text chunking strategies, and metadata indexing.
  • Local Kinyarwanda context grounding using the EjoChat API.

Practical Lab: Ingest documents, convert them into vector embeddings, and build a local database retrieval pipeline.

Session Deliverables: A FastAPI route that queries Qdrant to retrieve matching source context and returns a RAG-grounded response.
